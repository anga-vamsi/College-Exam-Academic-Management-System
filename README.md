# College Exam & Academic Management System

A Flask and MySQL based DBMS project for managing college academic and examination activities.

## Technologies

- Python
- Flask
- MySQL 8.0
- HTML
- CSS
- JavaScript
- mysql-connector-python

## Main Modules

- Student Management
- Faculty Management
- Department Management
- Course Management
- Subject Management
- Exam Management
- Exam Scheduling
- Marks Management
- Result Management
- Attendance Management
- Academic Reports
- Performance Reports

## Database Features

- Primary Keys
- Foreign Keys
- Constraints
- Triggers
- Views
- Stored Procedures
- Transactions
- Indexes
- Aggregate Queries
- Joins
- Window Functions
